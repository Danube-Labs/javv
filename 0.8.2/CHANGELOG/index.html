Changelog¶

0.8.2 (2026-10-16)¶

Features¶

  • deploy/compose/setup.sh makes .env with random secrets and shows the admin password once (#870) (856b5ec), closes #869
  • the scanners pull images from private registries with a login that the chart mounts (#880) (d02b951)

Bug Fixes¶

  • a sign-in whose cookie the browser did not keep says why, not success (#871) (669ad0c), closes #869
  • bootstrap reads the mapping of an index behind an alias of the same name (#876) (e874587)
  • findings and running images open with a bad stored hidden-columns value (#882) (13a09b4)

0.8.1 (2026-10-15)¶

Features¶

  • the guide's section heads are bands in the table-head colors (#864) (0583a3a)

Bug Fixes¶

  • a scheduled bulk triage checks its patch, at enqueue and in the drain (#855) (59a9ec4)

0.8.0 (2026-10-14)¶

Bug Fixes¶

  • a 422 from a field check names the field and the reason, not the value sent (#849) (1bf192f)
  • a full or red store says so, an overloaded one says busy, and readiness stays up (#843) (5858383)
  • cluster delete holds for re-deletes, mints, the bring back race and the nightly pass (#834) (9a60db0)
  • deps: update dependency zensical to v0.0.70 (#838) (6399aca)
  • index-map has the new ingest reasons, comments explain, mints log the tombstone they end (#836) (39e4014)
  • ingest refuses made-up scan orders, wrong clocks and naive times; a lost store is a 503 (#835) (c290f37)
  • password changes journal first, and sign-in says when a session or a change ended (#841) (3977cdd)
  • refused reads say so instead of showing an empty or stale answer (#840) (281abed)
  • release workflows: syft and the self-scan grype by digest, and a re-run signs what is published (#847) (b95b16d)
  • retirement notices: a shared code for the mid-delete 409, one bulk write, names in the bell, ticking fleet chips (#846) (3ba9a0e)
  • serve the fonts from the app, with spline sans mono as the mono face (#827) (8130999)
  • the scanner pulls the digest a pod runs, and a cycle retries for up to 6 minutes (#837) (0eeda33)
  • the web app closes the searches it leaves, and Prev from the last page works (#845) (581fa8f)

Miscellaneous Chores¶

  • the next release is 0.8.0, and its upgrade note says so (#853) (11ceb2d)

0.7.2 (2026-10-11)¶

Bug Fixes¶

  • a fresh install can mint its first token and read its settings pages (#820) (436e91e)
  • a refused read no longer reads as an empty answer (#821) (601385e)
  • scan pods started by digest through the pullable image_id reference (#819) (2b0e9c2)
  • the primary button presses in with a ring (#824) (373254e)

0.7.1 (2026-10-10)¶

Bug Fixes¶

  • a session with a temporary password reaches only the password change, reads included (#805) (beb6ef2)
  • every read checks that an ok reply's body arrived, and a lost token value says so (#813) (5eec52e)
  • overview reads survive an ok reply with no body, and logged errors say where they threw (#812) (4f36248)
  • the rig login helpers read with the session the password change returns (#808) (a58e788)

Features¶
