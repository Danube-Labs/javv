# Issue 1247: all proposed text changes of slices S1 to S4

- **Before** is `main`. **After** is the branch of each slice, after the strict STE review. S1 to S3 are in PR 1255. S4 (Settings, the Data inspector and About) is on a local branch on top of it.
- Each folder `S1/` to `S4/` holds one folder for each screen: `before.png`, `after.png` and `ab.png` (the two side by side).
- A row with "no picture" is a tooltip, a toast, a screen-reader label or a state that the stack cannot show.
- A row marked **ruled** changes the words of an older operator ruling, as the operator ruled on 2026-11-17 ("change all"). The behavior of that text stays.

## For triage

- **No promises.** Three notices said that a past time works "until the v1.1 metrics rollup". They now say only what the page does. All clusters says "This page cannot show a past time". Scanner status says "This page cannot show the scanner status of a past time".
- **A label wraps.** On Scanner status, "findings · last scan" takes two lines (picture `S3/06-scanner-status`).
- **S4 scope.** The plan names Settings for S4. S4 also holds the Data inspector, the jobs table and About, because they are the last screens outside the Guide.
- **S4 renamed labels.** The MCP level "Write and risk accept" is now "Write and accept risks" (the MCP user page too). "Ingest endpoint" is now "Scan endpoint". "Temp password" is now "Temporary password". About says "Database schema" for "Store schema", and so does UPGRADING.md.
- **S4 marks.** In the Roles table, the "no" mark is now "-" in place of an en dash, as in the other tables.
- **Kept as it is. The panel titles "Scan ingest", "Failed ingests" and "Vulnerabilities over time" stay. The refused-scans table still names no retry action.
